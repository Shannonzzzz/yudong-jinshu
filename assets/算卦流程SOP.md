# 玉洞金书算卦流程 SOP

## 一、用途与核心方法

本 SOP 根据同目录《玉洞金书 校对.docx》整理，适用于按该稿的条目查占断语。全书以**所报时辰**为起点，根据**所问事项**选定地支，顺数得到一个天干，再用“天干＋事项地支＋时辰地支”组成三字，查找对应断语。

原文起法是“就于所说时位起甲乙丙丁戊己庚辛壬癸数至所占位便见一干二支断词于后”。原文没有详细规定取时方式；实际操作可先记录问占时的时辰，但这是便于执行的约定，不应说成原文明确规定。

**流程：** 明确问题 → 确定事项地支 → 记录所报时辰地支 → 从该时辰起甲顺数到事项地支 → 组成三字 → 查原文对应条目 → 综合等级、词句和断语 → 记录结果。

## 二、起算前准备

1. **明确一个具体问题。** 先判断属于哪一类；如果问题混合了几个不同事项，分别记录，避免将不同类别混为一谈。
2. **记录所报时辰。** 使用者可以报地支时辰，例如“卯时”。若只有钟点，可参考下方时辰表转换；在记录中写明采用的钟点和转换方法。
3. **找到原文。** 需要用三字卦名查找原文对应段落；本 SOP 的速查表只帮助确定卦名，完整判断仍要读原文。

### 事项与地支对照

| 地支 | 原文类别 | 实际理解 |
|---|---|---|
| 子 | 财 | 求财、财利 |
| 丑 | 信 | 消息、音信 |
| 寅 | 婚 | 婚姻、婚配 |
| 卯 | 行人 | 出行、远行或在外行人情况 |
| 辰 | 贵 | 见贵人、求见或请人提携 |
| 巳 | 遗失 | 遗失的财物 |
| 午 | 逃 | 逃走、走失的人 |
| 未 | 求谋 | 谋事、求望 |
| 申 | 讼 | 官司、争讼 |
| 酉 | 病灾 | 疾病、灾患 |
| 戌 | 交易 | 买卖、交易 |

对应原文口诀：“子财丑信婚居寅，卯上行人贵在辰，遗失巳兮逃在午，求谋未上讼归申，酉病灾迍交易戌，亥宫却是孕中人。”类别边界不能从口诀中完全确定；遇到交叉问题，先写下选择理由。

## 三、手工起算

### 第 1 步：确定两个地支

- **起点：** 所报时辰的地支。
- **终点：** 所问事项对应的地支。

这两个地支各有用途，组成卦名时次序是“事项在前、时辰在后”。

### 第 2 步：从起点起甲，顺数到终点

按照“子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥”的顺序前进；天干按“甲、乙、丙、丁、戊、己、庚、辛、壬、癸”依次对应。**起点本身就算第一位，配甲。**

- 数到亥之后继续从子开始，不能倒数。
- 天干数到癸之后，从甲重新开始；不要将十二地支和十天干误认为同长度。
- 起点与终点相同时，第一位即到终点，所得天干为甲。
- 以起点为第 1 位数到第 11 位为甲，第 12 位为乙。

### 第 3 步：组成三字卦名

**卦名 = 数到终点时的天干 + 事项地支 + 起点时辰地支。**

例如“丙寅子”中，丙是数得的天干，寅是婚姻事项，子是所报时辰。三个字都要核对，不能只按一个天干或一个地支查。

### 第 4 步：在原文中查条目

1. 在 Word 中搜索完整的三字卦名。
2. 检查该条后面的词牌名与等级，例如“西江月 上上”。词牌名是文本标识，不参与起算。
3. 先读对应词句，再读紧随其后的“占……”简断，结合所问事项理解。等级如“上上”“中中”“下下”，作为原文标示记录，不能替代完整断语；原稿也有“上中”等标记。
4. 提取原文实际提到的结果、条件、阻碍、可能的时日或方位；原文未给出的信息标为“未说明”。
5. 词句与简断不一致时并列记录，不擅自选一个作为确定结论。例如“乙午未”的词句提及巳、寅，简断提及庚申，两处时日表述不同。

## 四、三个算例

### 例 1：子时问婚姻

1. 时辰为子；婚姻对应寅。
2. 子起甲、丑乙、寅丙，到寅停止。
3. 组合为 **丙寅子**。
4. 原文标“上上”，简断为婚姻和合、心下多疑。应同时记录有利表述和疑虑，不只记等级。

### 例 2：卯时问求财

1. 时辰为卯；求财对应子。
2. 卯甲、辰乙、巳丙、午丁、未戊、申己、酉庚、戌辛、亥壬、子癸。
3. 组合为 **癸子卯**。
4. 原文标“中中”，简断提到遇贵人、同辈相投。这里的“贵人”等是原文判断，记录时保留其条件。

### 例 3：子时问交易，检查天干循环

1. 时辰为子；交易对应戌。
2. 子甲、丑乙、寅丙、卯丁、辰戊、巳己、午庚、未辛、申壬、酉癸、戌甲。
3. 组合为 **甲戌子**。第 11 位重新回到甲。
4. 原文标“下下”，词句与简断涉及劳力、谋事未成、小大有别。保留原文表述，具体问题需要结合上下文阅读。

## 七、使用边界与校核

- 该稿包含 144 个不同的三字标题，与十二时辰 × 十二事项的组合相符；不应省略第三字，也不要把一干二支误作普通六十甲子。
- 原文没有明确规定要摇钱、掷筮、排六爻或使用出生年月日；这些不属于本稿已给出的起算步骤。
- 个别文字可能有校对、转写或表述上的疑点；原文也未充分解释取时及不同断语的取舍。本 SOP 标注可确认的规则，不替缺失内容补造定论。
- 这是对传统占断文本的整理。涉及疾病、孕产、财务或人身安全的叙述不构成专业判断；文中关于失物或走失的推断也不能作为指认具体人员的证据。
